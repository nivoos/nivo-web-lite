# Concepts

The app's persistent shared context: its terms, data model, naming and business rules, and the folders that hold them. Read this table first, then the concept
of every folder you are about to touch, before you read code. History, decisions, progress and status do not live here.

nivo-web-lite is the NIVO Web company repository: the CRM service (`be/`), its database (`db/`) and the NIVO Web package (`packages/nivo-web`) authored with the
published `@starci/nivoos-sdk`, `@starci/nivoos-cli` and `@starci/nivoos-provider-templates`.

| Concept | Read when you touch (folders) | One line |
| --- | --- | --- |
| [conventions](conventions.md) | every folder | Naming of tables, keys, columns, migrations, API fields, errors and the package. |
